# 🎧 Nuclear Themes

A collection of custom themes for **Nuclear Media Player**.

Designed to give Nuclear a fresh look while keeping the interface clean, readable, and easy to use.

## 🎨 Themes

### 🌙 BloodMoon

A dark, dramatic theme built around deep reds and crimson accents.

* 🌑 Dark mode
* ☀️ Light mode
* 🔴 Crimson-inspired UI
* 🎵 Designed for a darker music-player aesthetic

### 🥑 CreamyAvocado

A soft, creamy theme with fresh avocado-inspired tones.

* 🌑 Dark mode
* ☀️ Light mode
* 🥑 Green accents
* 🤍 Soft, clean interface

### 🌌 Sora

A sleek, atmospheric theme with a modern and minimal feel.

* 🌑 Dark mode
* ☀️ Light mode
* ✨ Clean accent colors
* 🎧 Designed for everyday use

> **Every theme includes both Light and Dark modes.**

# 📥 Installation

## 1. Download a theme

Choose the theme you want from the folders above and download the theme files.

For example:

```text
BloodMoon/
├── Light/
└── Dark/
```

## 2. Locate Nuclear's theme directory

Open Nuclear Media Player and locate its theme/customization directory.

Place the downloaded theme files into the appropriate theme folder.

> **Tip:** Keep the Light and Dark files separated if the theme package provides separate files for each mode.

## 3. Enable the theme

Restart Nuclear Media Player if necessary.

Open Nuclear's theme/customization settings and select the theme.

Choose either:

**☀️ Light Mode**

or

**🌙 Dark Mode**

depending on your preference.
